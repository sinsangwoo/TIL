# 2026-08-27

- GitHub MCP의 `create_or_update_file`이 403 `Resource not accessible by personal access token`을 내면 토큰 스코프 문제다. `gh auth status`로 CLI 쪽 토큰(`repo` 스코프)이 살아있으면 임시 클론 → commit → push로 우회하는 게 토큰 재발급보다 빠르다.
- 포트폴리오 README의 "production-grade / enterprise-grade / SOTA" 같은 수식어는 레포 메타데이터(스타·포크·커밋 분포)와 대조하면 근거 유무가 바로 드러난다. 병렬 조사 에이전트로 레포별 실사를 돌리면 사람이 읽는 것보다 빠르다.
- FNO/PINN 프로젝트의 "100–1000× faster than solvers"류 수치는 대부분 학습된 모델의 추론 1회 vs 전통 솔버의 전체 해석을 비교한 것이다. 학습 비용이 빠져 있어 일반화된 속도 주장으로 쓰면 과장이 된다.
- ONNX 변환(`tf2onnx`)은 포맷 변환이지 양자화가 아니다. 파일 크기가 줄어드는 건 부수 효과이므로 "quantization으로 경량화했다"고 쓰면 사실과 다르다.
- 빈 저장소(커밋 0개)도 프로필 표에는 설명과 함께 올라가 있을 수 있다. 포트폴리오 점검 시 링크가 아니라 실제 커밋 유무를 확인해야 한다.
